# Quiz Game (Python)

This is a simple command-line **True/False quiz game** built using Python. The quiz asks a series of questions and gives the user instant feedback, keeping track of the score.

## 📚 About the Project

This project is part of the **100 Days of Code – The Complete Python Pro Bootcamp for 2023** by [Dr. Angela Yu](https://www.udemy.com/course/100-days-of-code/). I'm currently enrolled in this course and used the structure provided in the lesson to build and expand this quiz app.

## 🧠 Features

- Object-Oriented Programming structure with `Question` and `QuizBrain` classes
- Score tracking after each question
- Case-insensitive answer checking
- Final score displayed at the end of the quiz
